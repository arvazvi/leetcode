# 114. Flatten Binary Tree to Linked List

Given the `root` of a binary tree, flatten the tree into a "linked list" in place.

* The linked list should use the same `TreeNode` class where the `right` pointer points to the next node in the list and the `left` pointer is always `None`.
* The nodes in the linked list should follow the order of a pre-order traversal of the original binary tree.

Follow up: Can you flatten the tree in-place without using extra space?
